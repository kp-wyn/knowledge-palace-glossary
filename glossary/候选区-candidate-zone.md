# 候选区

## 中文

新想法、待确认内容的临时存放区，经加工验证后才进入正式知识库。灵感和半成品不能直接污染正式库，也不能随手丢弃；候选区提供"先收、再验、后定"的入口。

## English

A temporary holding area for new ideas and unverified content, which only enters the formal library after processing and validation. Drafts shouldn't pollute the main library but shouldn't be discarded either — the candidate zone provides a "collect, verify, then decide" entry.

## 典型场景 / Typical Scenarios

- 临时灵感、半成品设想先入区 / Fleeting ideas, half-baked concepts go here first
- 待核实信息先入区 / Unverified information goes here first
