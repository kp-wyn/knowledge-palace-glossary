# 私有部署

## 中文

把知识宫殿（含模型、技能、知识库与治理）部署在个人或组织自己可控的环境里——本地服务器、私有云或本地设备，**数据不出域**，与“公有云多租户平台”相对。它是技能治理与可控性的基础：只有部署在自己手里，身份、权限、审计与数据才能完全控制。

三种部署模式：**纯云端 / 混合 / 完全本地化**；金融、医疗、政府等强合规场景与高敏感客户通常选择混合或完全本地化。封闭性不是隔绝，而是“**可控的开放**”——通过 MCP 接入外部工具，但数据不出域。

## English

Deploying the Knowledge Palace (models, skills, knowledge base and governance) in an environment controlled by the individual or organization — on-premise servers, private cloud or local devices — with **data staying in-domain**, as opposed to a public multi-tenant cloud. It is the foundation of skill governance and controllability: only when deployed in your own environment can identity, permissions, audit and data be fully controlled.

Three deployment modes: **fully cloud / hybrid / fully on-premise**; highly regulated domains such as finance, healthcare and government, and highly sensitive clients, usually choose hybrid or fully on-premise. Closedness is not isolation but “**controlled openness**” — connect to external tools via MCP while data stays in-domain.

## 典型场景 / Typical Scenarios

- 财税、医疗、政府等强合规客户，数据高度敏感 / Strongly regulated clients with highly sensitive data
- 客户数据需按客户隔离、核心方法论封装为技能黑盒 / Client-data isolation and core methodology packaged as a skill black box
- 离开公有平台、对 AI 与数据要求完全可控 / Full control over AI and data outside a public platform
