# KP-4+1

## 中文

知识宫殿的五层架构缩写：**4层楼层 + 1个贯穿层**。

### 五层是什么

| 层 / Layer | 名字 / Name | 干什么 / Purpose |
|---|---|---|
| 第1层 / L1 | 地基层 / Foundation | 采集、存储原始素材 / Collect and store raw materials |
| 第2层 / L2 | 结构层 / Structure | 分类、建模、关联 / Classify, model, link |
| 第3层 / L3 | 加工层 / Processing | 提取知识、蒸馏技能 / Extract knowledge, distill skills |
| 第4层 / L4 | 调控层 / Regulation | 复盘、迭代、淘汰 / Review, iterate, prune |
| +1层 / +1 | 人机协同层 / Human-AI Layer | AI做执行，人做决策 / AI executes; humans decide |

### 为什么是"4+1"而不是"5"

因为第5层（人机协同）不是一个楼层，是贯穿所有楼层的协同机制——AI施工队在每一层都在干活，但每一层的验收权都在人手里。

## English

The five-layer architecture abbreviation of the Knowledge Palace: **4 floors + 1 cross-cutting layer**.

### Why "4+1" and not "5"

Because the 5th layer (human-AI collaboration) is not a floor — it's a mechanism that runs through all floors. The AI construction team works on every floor, but the approval authority on every floor stays with humans.
