# 表达外壳

## 中文

内核之外图形化界面层的统称。把"给AI看的内核"和"给人看的界面"分开，外壳可随身份、场景更换而内核不动。

## English

The collective term for the graphical interface layer outside the core. Separates "the core for AI" from "the interface for humans" — shells can be swapped by identity and scenario while the core stays untouched.

## 典型场景 / Typical Scenarios

- GUI、看板、大屏等一切图形化界面
