# 挂载模块

> Mounted Module

## 一句话定义
可整体挂载到宫殿、按需插拔的功能模块，是知识技能模块的装载形态。

## 为什么需要这个词
能力需要“用时挂上、不用卸载”，挂载模块让宫殿保持精简而能力可按需扩展。

## 典型场景
- 临时或专项能力以模块整体挂载

## 怎么用 · 怎么升级
- 通过 manifest 声明接口与依赖
- 整体挂载、可整体卸载
- 不改动内核
