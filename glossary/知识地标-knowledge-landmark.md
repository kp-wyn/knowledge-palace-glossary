# 知识地标

## 中文

承担验真、存放经检验权威知识的库区，按S、A、B分级、非终身制。输出需要可信参照系；地标库提供一批可放心引用的权威基准。

## English

The repository that hosts verified authoritative knowledge, graded S/A/B, non-lifetime. Output needs a trusted reference system; the landmark library provides authoritative baselines you can safely cite.

## 典型场景 / Typical Scenarios

- 收录经典理论、行业标准 / Store classic theories, industry standards
- 权威发布、稳定方法论 / Authoritative releases, stable methodologies
