# 加工层

> Processing Layer

## 一句话定义
知识宫殿的第三层，负责知识的提取、激活、迁移、组合创新与经验萃取。

## 为什么需要这个词
加工决定能不能真正消化。只摘不炼，素材越攒越多却长不出能力；这一层把“看过”变成“会用”。

## 典型场景
- 提取知识卡、跨域迁移、组合创新
- 把项目经验萃取成经验卡
- 蒸馏可挂载技能
