# 知识黑盒

## 中文

裸AI在没有任何技能、SOP、方法论挂载的状态下生成内容——内部推理过程不可见，输出结果不可预测，概率论上第一次产出通常不可用。

## English

An AI-generated output produced without any mounted skills, SOPs, or methodology frameworks — the internal reasoning process is opaque and results are unpredictable. In practice, the first output is rarely usable.

## 典型场景 / Typical Scenarios

- 直接问ChatGPT/豆包："帮我写个品牌方案" / Ask ChatGPT/Doubao directly: "write a brand plan"
- 反复抽五六次才碰到一个能用的 / Pull 5-6 times before getting one usable output
- 同样提示词每次结果不一样，无法复用 / Same prompt gives different results each time, impossible to reuse
