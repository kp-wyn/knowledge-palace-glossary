# 知识技能模块

## 中文

由一组挂载技能、特色库与专属知识组成的功能模块，封装某一领域的完整能力。单个技能只解决一个动作，复杂领域需要把技能、知识库打包成模块。

## English

A functional module composed of a set of mounted skills, special libraries, and dedicated knowledge, encapsulating complete capability in one domain. Single skills solve one action; complex domains need skills and knowledge bundled into a module.

## 典型场景 / Typical Scenarios

- 教学模块、质检模块
- GEO模块等成套能力
