# 知识沙箱

## 中文

隔离存放待验证内容、要求内容可证伪的库区，承担验疑。存疑内容直接入库有风险、直接丢弃可能浪费；沙箱提供"先观察、后定性"的缓冲。

## English

A repository that isolates unverified content requiring falsifiability, handling doubt verification. Uncertain content shouldn't enter the main library yet shouldn't be discarded either — the sandbox provides a "observe first, classify later" buffer.

## 典型场景 / Typical Scenarios

- 待确认AI内容隔离 / Isolate unconfirmed AI content
- 候选想法、争议结论隔离 / Isolate candidate ideas, disputed conclusions
