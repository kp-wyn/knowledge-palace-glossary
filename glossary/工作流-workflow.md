# 工作流

## 中文

多个技能或环节按固定顺序串联、逐级传递中间产物的标准作业流程。单技能内部的分工叫流水线；跨技能协同的整体编排叫工作流。工作流把“散点技能”编成可重复交付的流程，是技能协同的上层概念。

## English

A standard procedure where multiple skills or stages run in a fixed order, passing intermediate outputs stage by stage. Division inside one skill is a pipeline; cross-skill orchestration is a workflow. Workflow turns scattered skills into repeatable delivery and is the upper-level concept of skill collaboration.

## 典型场景 / Typical Scenarios

- 多技能协同编排 / Orchestrate multiple skills
- 交付 SOP 标准化 / Standardize a delivery SOP
- 周/月工作流模板 / Weekly or monthly workflow templates
