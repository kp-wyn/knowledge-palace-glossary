# 学习路径

> Learning Path

## 一句话定义
知识卡的附加字段，标注学习该知识的前置知识与延伸阅读，把孤立卡片串成进阶路线。

## 为什么需要这个词
单张卡无法说明“先学什么、再学什么”；路径让知识有先后、可循序渐进。

## 典型场景
- 为一个领域规划前置→核心→进阶卡片链
