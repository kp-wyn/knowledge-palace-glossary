# 技能资产清单

## 中文

一座宫殿（个人或企业）全部技能资产的**台账**，回答三个问题：**有哪些技能、谁在用、用得怎么样**。它为每个技能登记身份、归属、权限、使用情况与状态，是技能治理层的“资产底账”，让宫殿主人对自己的 AI 能力可见、可盘、可管。

个人宫殿由主人自盘；企业宫殿由知识管理员与宫殿架构师协作建立、定期盘点。其可视化形态包括技能资产看板、权限矩阵图与调用热力图。

**能力公式**：技能资产清单 = 身份登记 × 归属权限 × 使用度量 × 状态盘点

| 登记维度 | 关键字段 |
| ---- | ---- |
| 身份 | ID、名称、触发词、版本、所有者、创建时间 |
| 归属 | 所属部门 / 项目、负责人 |
| 权限 | 可使用角色、可访问数据、可调用工具 |
| 使用 | 调用频率、成功率、质量评分、最近调用时间 |
| 状态 | 创建 / 测试 / 上线 / 监控 / 迭代 / 下线 |

## English

The **ledger** of all skill assets in a palace (individual or enterprise), answering three questions: **what skills exist, who is using them, and how well they perform**. It records each skill's identity, ownership, permissions, usage and status. It is the asset register underpinning the Skill Governance Layer, making the palace owner's AI capabilities visible, countable and manageable.

For a personal palace the owner maintains it; for an enterprise palace the Knowledge Steward and Palace Architect build it together and audit it periodically. Its visual forms include the skill asset dashboard, the permission matrix and the call heatmap.

**Formula**: Skill Asset Inventory = Identity Registration × Ownership & Permissions × Usage Metrics × Status Inventory

## 典型场景 / Typical Scenarios

- 企业一次性盘点所有 AI 工具与技能，建立管理台账 / An enterprise takes a one-time inventory of all its AI tools and skills and builds a management ledger
- 定期盘点，识别闲置技能、高频技能与质量下滑技能 / Periodic audits reveal idle skills, high-frequency skills and skills whose quality is declining
- 作为技能治理咨询与交付的第一步 / Serve as the first step of skill-governance consulting and delivery
