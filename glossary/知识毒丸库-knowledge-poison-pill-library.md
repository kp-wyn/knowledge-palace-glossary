# 知识毒丸

## 中文

被验证为错误的知识——伪科学、AI幻觉、认知误区、失败想法。它们不是"没用的信息"，而是"有毒的信息"：你以为它是真的，用了就会出事。集中收录错误并标注成因，是组织最便宜的教训资产。

## English

Knowledge verified as wrong — pseudoscience, AI hallucinations, cognitive biases, failed ideas. Not just "useless" but "toxic": you think it's true, and using it causes damage. Collecting errors with root causes is an organization's cheapest lesson asset.

## 典型场景 / Typical Scenarios

- 收录五类错误：伪科学、AI幻觉、认知偏差、失败想法、过时知识 / Store five error types: pseudoscience, AI hallucination, cognitive bias, failed ideas, outdated knowledge
- 新决策前先查毒丸库，避免重蹈覆辙 / Check the poison-pill library before new decisions to avoid repeating mistakes
- 失败项目教训、被证伪想法集中存放 / Failed project lessons, falsified ideas stored centrally
