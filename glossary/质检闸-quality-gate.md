# 质检闸

## 中文

内容对外输出前必须通过的强制检验关口，三验一密在此执行。没有强制关口，质检靠自觉就会形同虚设；闸口保证每件输出都经过检验。

## English

The mandatory checkpoint every output must pass before external release, where Three Verifications One Encryption is enforced. Without a hard gate, voluntary quality checks become empty; the gate ensures every output is inspected.

## 典型场景 / Typical Scenarios

- 知识入库前过闸 / Pass through the gate before knowledge enters
- 作品发布、对外交付前过闸 / Pass through the gate before publishing or external delivery
