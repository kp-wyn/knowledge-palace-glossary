# 技能闭环

> Skill Loop

## 一句话定义
技能投入工作、产出成果、由成果反馈再优化技能的完整循环。

## 为什么需要这个词
技能不经过真实工作检验就无法进化；闭环让技能越用越强、越用越准。

## 典型场景
- 技能上线→真实项目使用
- 看成果→迭代技能
