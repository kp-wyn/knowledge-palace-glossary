# 技能闭环

## 中文

技能投入工作、产出成果、由成果反馈再优化技能的完整循环。技能不经过真实工作检验就无法进化；闭环让技能越用越强、越用越准。

## English

The complete cycle where a skill is applied to work, produces results, and those results feed back to improve the skill. Skills can't evolve without real-world testing; the loop makes them stronger and more accurate with use.

## 典型场景 / Typical Scenarios

- 技能上线→真实项目使用 / Skill goes live → used in real projects
- 看成果→迭代技能 / Review results → iterate the skill
