# 知识宫殿裙房模块

> Palace Annex Module

## 一句话定义
挂在主体建筑旁的即插即用、可挂载可拆卸的独立功能模块，用于临时爱好、专业领域或特定业务。

## 为什么需要这个词
不是所有功能都该进主体内核；裙房承载个性化、临时性需求，保证主体精简稳定。

## 典型场景
- 小说创作裙房、临时爱好裙房
- 专项业务裙房

## 怎么用 · 怎么升级
- 通过 KP-Annex 挂载
- 分 hobby、professional、business 三模式
- 可插拔、不改内核；默认不主动加
