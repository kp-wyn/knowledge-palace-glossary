# 价值飞轮

> Value Flywheel

## 一句话定义
知识积累→技能封装→场景应用→成果产出→反馈沉淀，再反哺知识积累的正向循环。

## 为什么需要这个词
各环节一旦转起来会自我增强、越转越快；飞轮是知识宫殿持续增值、形成壁垒的底层机制。

## 典型场景
- 每完成一个项目就沉淀知识与技能
- 沉淀反哺下一个项目
