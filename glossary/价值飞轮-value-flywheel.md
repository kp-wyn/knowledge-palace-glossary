# 价值飞轮

## 中文

知识积累→技能封装→场景应用→成果产出→反馈沉淀，再反哺知识积累的正向循环。各环节一旦转起来会自我增强、越转越快。

## English

The positive loop: knowledge accumulation → skill encapsulation → scenario application → output → feedback, feeding back into knowledge accumulation. Once spinning, each stage reinforces the others and accelerates.

## 典型场景 / Typical Scenarios

- 每完成一个项目就沉淀知识与技能
- 沉淀反哺下一个项目
