# 治理控制面看板

## 中文

技能治理层的**可视化控制面**，把治理状态集中呈现，统辖五个视图：

| 视图 | 看什么 |
| ---- | ---- |
| ① 技能资产看板 | 有多少技能、分类、使用频率、健康度 |
| ② 权限矩阵图 | 谁能用什么技能、能看什么数据 |
| ③ 调用热力图 | 哪些技能高频使用、哪些闲置 |
| ④ 审计日志视图 | 谁在何时用了什么技能、输出了什么 |
| ⑤ 异常告警面板 | 失败、质量下降、成本超支的实时告警 |

是企业版知识宫殿的“驾驶舱”。概念与五视图框架可公开；具体版式、阈值与内部指标属内部资料。

## English

The **visual control plane** of the Skill Governance Layer, centralizing governance status across five views:

| View | Shows |
| ---- | ---- |
| ① Skill asset dashboard | how many skills, categories, usage frequency, health |
| ② Permission matrix | who can use which skill, see which data |
| ③ Invocation heatmap | which skills are heavily used, which idle |
| ④ Audit-log view | who used what when, and the output |
| ⑤ Exception-alert panel | real-time alerts for failure, quality decline, cost overrun |

The “cockpit” of the enterprise Knowledge Palace. The concept and five-view framework are public; specific layouts, thresholds and internal metrics are internal.

## 典型场景 / Typical Scenarios

- 企业多技能、多 Agent 的统一监控 / Unified monitoring of many skills and agents
- 知识管理员定期盘点、审计与对账 / Periodic inventory, audit and reconciliation by the Knowledge Steward
- 异常实时发现与处置 / Real-time detection and handling of exceptions
