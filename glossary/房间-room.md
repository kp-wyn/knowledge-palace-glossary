# 房间

## 中文

每一层内的功能单元，如地基层的采集箱、结构层的分类体系。楼层太大无法直接使用，房间把一层拆成若干各司其职的功能单元。

## English

Functional units within each floor, such as the collection box on the Foundation floor or the classification system on the Structure floor. Floors are too large to use directly; rooms break them into dedicated functional units.

## 典型场景 / Typical Scenarios

- 地基层的采集箱 / Foundation floor intake box
- 加工层的AI对话蒸馏间、风险预警工坊 / Processing floor AI-distillation room, risk-alert workshop
