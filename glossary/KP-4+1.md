# KP-4+1

## 一句话定义
知识宫殿的五层架构缩写：**4 层楼层 + 1 个贯穿层**。

| 层 | 名字 | 干什么 |
|---|---|---|
| L1 | 地基层 Foundation | 采集、存储原始素材 |
| L2 | 结构层 Structure | 分类、建模、关联 |
| L3 | 加工层 Processing | 提取知识、蒸馏技能 |
| L4 | 调控层 Regulation | 复盘、迭代、淘汰 |
| +1 | 人机协同层 Human-AI | AI 做执行，人做决策 |

## 为什么需要这个词
它用最简方式说清知识宫殿的结构，并且强调“为什么是 4+1 而不是 5”：第五层（人机协同）不是一个楼层，而是贯穿所有楼层的协同机制——AI 施工队在每一层都干活，但每一层的验收权都在人手里。

## 典型场景
- 向别人一句话介绍知识宫殿的整体架构
- 新建宫殿时按五层落目录、定职责
- 判断某件事该归“楼层”还是归“贯穿的人机协同”
