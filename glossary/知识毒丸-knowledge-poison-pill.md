# 知识毒丸

## 中文

被验证为错误的知识——伪科学、AI幻觉、认知误区、失败想法。它们不是"没用的信息"，而是"有毒的信息"：你以为它是真的，用了就会出事。

知识毒丸库是专门存放这类错误知识的库区，承担验错功能，供反面学习。

### 为什么需要这个词

错误不显性留存就会反复重犯。集中收录错误并标注成因，是组织最便宜的教训资产。

### 五类知识毒丸

1. **伪科学**：被证伪但广泛流传的说法
2. **AI幻觉**：AI一本正经胡说八道的内容
3. **认知偏差**：导致判断失误的思维定式
4. **失败想法**：曾经试过但走不通的路
5. **过时知识**：曾经对但现在失效的结论

### 怎么用

- 验证为错即入库
- 写明错误内容与成因
- 新决策前先查毒丸库——避免重蹈覆辙

## English

Knowledge that has been verified as wrong — pseudoscience, AI hallucinations, cognitive biases, failed ideas. These aren't just "useless information"; they're "toxic information": you think they're true, and using them causes damage.

The Poison Pill Library is the dedicated repository for such errors, serving as a reverse-learning mechanism.

### Why this matters

Errors that aren't explicitly recorded will be repeated. Collecting errors with their root causes is an organization's cheapest lesson asset.

### Five types

1. **Pseudoscience**: debunked claims still widely circulated
2. **AI hallucinations**: AI confidently wrong content
3. **Cognitive biases**: mental patterns that cause judgment errors
4. **Failed ideas**: paths that were tried but didn't work
5. **Outdated knowledge**: conclusions that were true but no longer valid
