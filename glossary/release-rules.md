# 放行规则

> Release Rules

## 一句话定义
三验一密的最终判定规则，以放行口诀决定内容能否入库或发布。

## 为什么需要这个词
各验完成后需要一条明确、可执行的总判定，避免“差不多就放行”。

## 典型场景
- 入库前逐条核对口诀
- 发布前逐条核对口诀

## 怎么用 · 怎么升级
- 疑未解、真未验、错未除、密未脱、规未合
- 任一不满足不放行
