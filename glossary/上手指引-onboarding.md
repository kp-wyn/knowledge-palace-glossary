# 上手指引

## 中文

知识宫殿交付给使用者的“第一次使用引导”，说明宫殿怎么进门、第一步做什么、先建哪个区。新殿主面对空宫殿容易不知所措；上手指引把“先做什么”固化成一条最短路径，让第一次使用有方向、不冷场。

## English

The first-use guide delivered with a Knowledge Palace, telling a new owner how to enter, what to do first, and which zone to build first. A brand-new palace can overwhelm newcomers; onboarding fixes a shortest path for “what to do first”, giving first-time use direction and warmth.

## 典型场景 / Typical Scenarios

- 整殿交付包附上手指引 / Attach onboarding to a palace delivery package
- 新殿主第一次打开宫殿 / A new owner opens the palace for the first time
- 挂载技能的使用说明 / Usage notes for a mounted skill
