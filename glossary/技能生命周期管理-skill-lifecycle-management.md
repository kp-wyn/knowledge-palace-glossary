# 技能生命周期管理

## 中文

对技能**从生到灭**全程的阶段管控，让技能不是“创建后不管”，而是每个阶段都有标准、有门禁、有责任人。标准链路为：**创建 → 测试 → 上线 → 监控 → 迭代 → 下线**。裙楼模块对应链路为：**安装 → 测试 → 启用 → 监控 → 更新 → 卸载**。

**能力公式**：技能生命周期管理 = 阶段划分 × 质量门禁 × 责任人 × 状态流转

| 阶段 | 关键动作 | 门禁 / 产出 |
| ---- | ---- | ---- |
| 创建 | 定用途、触发词、所有者，分配 ID | 立项登记 |
| 测试 | 沙箱演练，质量与安全校验 | 测试通过 |
| 上线 | 按角色 / 部门 / 项目授权后发布 | 发布记录 |
| 监控 | 调用频率、成功率、质量评分、异常告警 | 监控看板 |
| 迭代 | 依据监控与复盘更新版本 | 新版本 |
| 下线 | 停用、归档、回收权限 | 归档记录 |

## English

Stage-by-stage governance of a skill **from creation to retirement**, so a skill is not left unmanaged after being created: every stage has standards, gates and an owner. The standard chain is **Create → Test → Deploy → Monitor → Iterate → Retire**. For annex modules the chain is **Install → Test → Enable → Monitor → Update → Uninstall**.

**Formula**: Skill Lifecycle Management = Stage Definition × Quality Gates × Ownership × State Transitions

## 典型场景 / Typical Scenarios

- 新技能从沙箱测试到授权上线的标准化发布 / Standardized release of a new skill from sandbox testing to authorized deployment
- 依据监控数据迭代技能、淘汰闲置或失效技能 / Iterate skills based on monitoring data and retire idle or ineffective ones
- 裙楼模块的安装、启用、更新与卸载管理 / Manage the installation, enabling, updating and removal of annex modules
